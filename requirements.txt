# This program has exactly one external dependency.
#
# Nothing is installed from this file on the store PC: the program never runs
# `pip install`. The launcher looks for a Python that already has openpyxl
# among the candidates it knows about and, if none is found, stops and
# explains how to add it, rather than adding it itself.
#
# This file serves two other purposes: it tells CI what to test against, so
# the machine that sees commits before the store matches the store; and it
# tells anyone opening the repository what needs to already be present.
#
# The upper bound isn't generic caution. openpyxl serializes with lxml when
# it's available and with xml.etree otherwise, and the two write an empty
# element differently — a mismatch that showed up as tests passing on one
# machine and failing on another. A minor version bump needs checking first:
# verify openpyxl serializes an empty element the same way with and without
# lxml installed.
openpyxl>=3.1,<3.2   # tested with 3.1.5

# Node 18+ is needed to write `.xlsx` files and doesn't appear here, because
# nothing is installed: the writer uses only Node's standard library, and
# `find_node_runtime()` locates the executable.
